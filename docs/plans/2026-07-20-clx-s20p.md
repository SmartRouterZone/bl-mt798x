# CLX S20P implementation plan

## Goal

Provide BL2 and FIP/U-Boot build inputs for the regular CLX S20P OpenWrt image
while retaining the `dhcp` branch's persistent DHCPv4 server behavior.

## Files

- Create `uboot-mtk-20230718-09eda825/arch/arm/dts/mt7986a-clx-s20p.dts`.
- Create `uboot-mtk-20230718-09eda825/configs/mt7986_clx_s20p_defconfig`.
- Create `atf-20240117-bacca82a8/configs/mt7986_clx_s20p_defconfig`.

## Steps

1. Define the S20P's 2 GiB memory map and bootloader-visible GPIO devices.
2. Enable the eMMC controller with the board's 8-bit `emmc_51` pin group,
   1.8 V/3.3 V supplies, hardware reset, and 200 MHz limit.
3. Enable GMAC0's 2.5G fixed link to the MT7531 switch and use GPIO 5 for the
   switch reset line.
4. Enable the MediaTek eMMC boot menu, web failsafe, fixed management address,
   and related commands in the board defconfig. The existing Kconfig default
   then selects the lightweight DHCPv4 server.
5. Add an ATF DDR4/eMMC target with a matching board name so `build.sh` can
   produce `mt7986_clx_s20p-bl2.bin` and `mt7986_clx_s20p-fip.bin`.
6. Run whitespace, file-scope, config parity, and device-tree reference checks.
   A full `make` build is deferred until separately approved by the user.
